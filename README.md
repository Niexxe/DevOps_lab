# DevOps Labs

Учебное портфолио по основам DevOps: шесть лабораторных работ с описанием выполнения, результатами и скриншотами.

**Автор:** Никитин Георгий Александрович  
**Дисциплина:** Основы DevOps, МТУСИ

## Лабораторные работы

| № | Работа | Содержание |
| --- | --- | --- |
| 1 | [Linux и Bash](labs/01-linux-bash/README.md) | CLI, файловая система, скрипт удаления файлов |
| 2 | [Git](labs/02-git/README.md) | Коммиты, удалённый репозиторий, ветвление и слияние |
| 3 | [Docker](labs/03-docker/README.md) | Контейнеры, логи, inspect, образы Python и Java |
| 4 | [Docker Compose](labs/04-docker-compose/README.md) | API, PostgreSQL, Nginx, сети и тома |
| 5 | [CI/CD](labs/05-ci-cd/README.md) | pytest, GitHub Actions, сборка и публикация образа |
| 6 | [Ansible](labs/06-ansible/README.md) | Inventory, переменные, роли и установка Nginx |

## Как пользоваться

Откройте нужную лабораторную в таблице. В каждой папке находятся `README.md` с отчётом и `assets/` с извлечёнными изображениями. Ссылки относительные: скриншоты открываются на GitHub и при локальном просмотре Markdown.

## Состав материалов

Материалы перенесены из пяти DOCX-отчётов и одного PDF. Титульные листы заменены заголовками; сохранены основной текст, выводы, контрольные вопросы и скриншоты. Текстовые листинги оформлены блоками кода. Изображения извлечены из документов без перерисовки.

Это репозиторий отчётов: полные исходники приложений, workflow и конфигураций, показанные только на скриншотах, не восстановлены. Ссылки на исходные репозитории сохранены там, где они были в отчётах. Команды и описанные результаты перенесены из отчётов; повторный запуск стендов при подготовке этого репозитория не выполнялся.
